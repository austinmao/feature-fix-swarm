## Implemented recovery slice

`ControlStore` now has immutable run-level dispatch/token reservations,
parent-bound child activities, cumulative reservations across revisions,
classified launch completion, and run-wide uncertainty checks. The existing
ownership, input selection, workspace journal, process identities, upstream
resolver, and event tables remain the underlying authority. No Ruflo runtime
dependency or generic artifact graph was added.

`managed-start` reuses the existing workspace-preparation implementation and
retains its owner while calling the supervisor. Unresolved child launches
retain ownership after callback failure. Explicitly selected managed
`gsd-run.sh` invocations enter that boundary before planning-wall or shell-state
writes. Refusals do not fall through to the legacy launcher.

The process transport commits a launch intent/debit, creates a waiting direct
child, records verified identity and initial HEAD, commits authorization, then
releases execution. A replayed or uncertain intent cannot launch a second
child. Output receipts are harvested by the supervisor before completion;
replaced output files and absent telemetry cannot become successful evidence.

The dispatch request key, immutable request material, launch intent and debit
now commit together in the existing event authority. A completed request
remains bound to its original intent after reopening the database; replay
cannot spend another allowance or spawn again. A changed request conflicts,
while an explicitly new request key remains subject to the original limits.

The supervisor can deliver a worker request endpoint and scope through the
committed permit. Both ends verify kernel peer identities. Requests use the
existing ControlStore event authority for replay protection; delegated work
creates a pending child activity and still requires separate supervised
admission. No owner token or database path is sent to the worker. This does
not prevent a same-user process from bypassing the channel without host
containment.

Uncertain accounting cannot be finalized while its actual child is alive,
cannot manufacture a missing authorization permit, and remains uncertain
through recovery. Terminal classifications also survive recovery.

A deterministic reproduction also exposed concurrent bootstrap observing a
published database before its lock protocol existed. The initializer now
uses a short verified-parent directory flock through publication and protocol
capture, releases it before normal database locking, and compares the full
identity before use. Interrupted provisioning remains refused without an
automatic repair. This lock does not span run execution.

The planning wall fails closed on missing or malformed counters. The legacy
runner no longer passes the primary filesystem path as `GSD_PROJECT` and
refuses same-run re-entry before probing when accounting is quarantined.
Mutable compatibility files remain insufficient authority for new runs.

The worker containment policy validates roots and runtime bindings and
revalidates its hash before producing platform arguments. The actual macOS
smoke attempt failed closed with the narrow supplied runtime roots; Linux
refuses until descendant controls are measured. Neither is qualified.
