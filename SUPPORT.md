# Support

## Usage help

Start with:

- [Getting started](docs/getting-started.md)
- [Choosing a command](docs/choosing-a-command.md)
- [Installer, migration, and rollback](docs/installer.md)
- [Configuration](docs/configuration.md)

If those guides do not answer the question, open a GitHub Discussion once
Discussions are enabled. Until then, use a regular issue and choose the most
relevant template. Include versions, operating system, install scope, doctor
output, and a minimal reproduction. Remove credential values and private
repository content first.

## Bugs and feature requests

Use the issue forms for reproducible bugs and focused feature proposals. The
issue tracker is not a channel for private consulting, urgent operational
support, or disclosing vulnerabilities.

## Security

Suspected vulnerabilities must be reported privately using
[SECURITY.md](SECURITY.md).
