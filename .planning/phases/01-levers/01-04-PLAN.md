<objective>
Build `scripts/gsd/learnings-harvest.sh`: a fail-soft harvester that reads a finished run's
`.planning/**/learnings*.jsonl`, writes distilled entries to gbrain when the backend is
healthy, else appends them atomically to `.feature-fix-swarm/learnings-archive.jsonl`, always
exits 0, and prints the harvested count (US2). Later (Phase 2) the feature-implement and
code-uplift finish tails invoke it — this phase builds and tests the lever only.

Purpose: gsd's own learnings loop is discarded at run end today; auto-harvesting it in the
finish tail means the next spec's planner benefits with no manual step (RESEARCH Architectural
Responsibility Map). It must never block ship, so it is fail-soft exit-0 throughout.

Output: learnings-harvest.sh + its bats coverage (backend stub, archive fallback, empty,
malformed lines).
</objective>

Fail-soft convention to mirror (scripts/gsd/security-model-fence.sh header + exits):
  "Fail-soft + never silent" — WARN on stderr, exit 0; a broken mechanism never blocks a run.
  `set -uo pipefail` (scripts/gsd/*.sh convention).

Backend probe (RESEARCH Standard Stack + plan.md architecture note):
  healthy iff `command -v gbrain` succeeds AND `env -u DATABASE_URL gbrain doctor` exits 0
  (the `env -u DATABASE_URL` is required — a shell-inherited DATABASE_URL redirects gbrain's
  pglite path; this is the repo's memory-routing discipline).

Atomic append (RESEARCH Pattern 5): for the JSONL archive, prefer a flock-guarded direct
append (`flock` if available) — an append is not a tmp+mv replace. `mkdir -p .feature-fix-swarm`
first. bash-3.2-safe (no mapfile/declare -A).
</interfaces>
