<objective>
Wire the two Phase-1 levers that review-gate owns into `skills/review-gate/SKILL.md`:
(1) a tier-selection preamble that calls `scripts/gsd/review-tier.sh` to size the
defect-pass pipeline to the diff's risk (US3, AC-004/AC-005), and (2) a findings
recording step that persists ALL merged findings via `gates.py findings-queue`
before the verdict, so fix rounds work the whole queue and re-runs skip resolved
signatures (US4, AC-007). Both are grep-pinned RED-first by a new bats file.

Purpose: a 2-file docs diff should not pay a 40-file auth review, and every review
pass should emit ALL findings with persisted signatures instead of short-circuiting
on the first blocking batch. review-gate is the biggest Phase-2 wiring (two levers,
one skill) so it gets its own plan.

Output: tests/bats/int-review-gate.bats (new), skills/review-gate/SKILL.md
(tier preamble + findings recording + version 1.4.0).
</objective>

review-tier.sh (scripts/gsd/review-tier.sh — frozen lever):
  Usage: review-tier.sh [--staged | --all | --file <path>]
    --staged (default) -> git diff --staged; if empty, git diff HEAD
    --all              -> git diff <base>...HEAD ; base = $REVIEW_TIER_BASE (default main)
    --file <path>      -> git diff -- <path>
  Env: REVIEW_TIER={light|standard|full} overrides (reason "override"); other values ignored.
       REVIEW_TIER_BASE (default main) for --all.
  stdout: exactly one line "<tier> <reason>" (tier in {light,standard,full}).
  stderr: all warnings; exit 0 on any classification (incl. fail-safe standard), 2 on usage error.
  Mode parity: review-gate's DIFF_TARGET is `--staged` (default) / `main` (--all) / `--file*`
    (SKILL.md:98-118) — pass review-tier the matching mode so both classify the same bytes.

findings-queue (lib/gates.py — frozen; CLI arm at lib/gates.py:1071):
  python3 "$GATES_PY" findings-queue add <file> <issue>   -> prints {"sig","deduped"}; exit 0
  python3 "$GATES_PY" findings-queue list [--unresolved]   -> prints JSON array; exit 0
  python3 "$GATES_PY" findings-queue resolve <sig>          -> exit 0 ok / 1 unknown sig / 2 usage / 3 schema
  Signature = full sha256 over structured [file, normalized_issue]; re-add same finding -> deduped:true, one entry.
  Store = $GATES_STORE (default .feature-fix-swarm/evidence.json), the SAME store preflight/grant use.

GATES_PY resolution (copy VERBATIM from scripts/gsd/review-gate-command.sh:~29-40):
  REPO_ROOT="$(git rev-parse --show-toplevel 2>/dev/null || pwd)"
  GATES_PY=""; for candidate in \
    "$REPO_ROOT/packages/feature-fix-swarm/lib/gates.py" \
    "$HOME/.claude/lib/feature-fix-swarm/gates.py" \
    "$REPO_ROOT/lib/gates.py"; do [ -f "$candidate" ] && GATES_PY="$candidate" && break; done
  (findings recording is best-effort: if GATES_PY is empty, WARN and continue — never block the verdict.)
