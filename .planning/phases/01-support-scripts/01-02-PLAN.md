<objective>
Build `scripts/gsd/state-phase.sh` (REQ-02): a bash transform that prints the
completed-phases integer derived from a STATE.md file's BODY `## Current Position`
section (never the known-unreliable frontmatter `percent`/`completed_phases`
counters), TDD-first with a hermetic fixture-based bats suite.

Purpose: FFS preflight and gates need a deterministic integer over gsd-side phase
progress. The frontmatter counters are a documented-unreliable upstream defect class
at the pinned gsd-core 1.6.1 (issues #1514/#1446/#1264/#274/#2012/#2022), so the
script routes around them by parsing the operator-facing BODY text.

Output: `scripts/gsd/state-phase.sh`, `tests/state-phase.bats`.
</objective>

- `scripts/gsd/state-phase.sh` — new CLI script; contract: `state-phase.sh [state-file]` (default `.planning/STATE.md`); exit 0 + single integer on stdout = success, exit 1 = body has no derivable `Phase: X of Y` line, exit 2 = state file missing or more than one argument
- `tests/state-phase.bats` — new bats suite for the script (hermetic; fixture STATE.md files written to `$BATS_TEST_TMPDIR`, no stubbing)

- Completed-phase derivation rule (new behavior contract): `COMPLETED = CURRENT` iff the body `Status:` line contains `phase complete` case-insensitively, else `CURRENT - 1`, floored at 0

<feature>
  <name>state-phase.sh — BODY-derived completed-phases integer from STATE.md</name>
  <files>scripts/gsd/state-phase.sh, tests/state-phase.bats</files>
  <behavior>
    Contract (REQ-02), exhaustively:
    - `state-phase.sh [state-file]` with zero or one arg; STATE_FILE defaults to
      `.planning/STATE.md` via `${1:-.planning/STATE.md}`.
    - More than one arg: `usage: state-phase.sh [state-file]` on stderr, exit 2.
    - STATE_FILE not a regular file: `state-phase: <path> not found` on stderr, exit 2.
    - Strip YAML frontmatter (a leading `---` on line 1 through the next `---` line)
      with awk BEFORE any grep, so frontmatter `percent`/`completed_phases` counters
      and any decoy `Phase:`-shaped frontmatter line are structurally unreadable.
    - Grep the remaining BODY for the first line matching
      `^Phase:[[:space:]]*[0-9]+[[:space:]]+of[[:space:]]+[0-9]+`; if none,
      `state-phase: no 'Phase: X of Y' line found in <path> body` on stderr, exit 1.
    - CURRENT = the leading integer of that line. COMPLETED = CURRENT when the first
      body `^Status:` line contains `phase complete` (case-insensitive grep -qi),
      else CURRENT - 1, floored at 0.
    - Print COMPLETED as a single integer line on stdout, exit 0. No other stdout.
  </behavior>
  <implementation>
    Copy 01-PATTERNS.md "scripts/gsd/state-phase.sh" section (RESEARCH.md Pattern 3)
    verbatim, adding only the arg-count guard. House style: `#!/usr/bin/env bash`,
    `set -uo pipefail` (no -e), bash-3.2-safe, all expansions double-quoted,
    grep -E only (never -P). Distinct exit-code scheme from consent-check.sh —
    do not conflate (exit 2 covers BOTH usage error and missing file here, per
    REQ-02's explicit "exits 2 if the file is missing").
  </implementation>
</feature>
